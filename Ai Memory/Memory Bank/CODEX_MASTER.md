## Важное ограничение

Known issue: после слоя кликабельных тегов возможна ошибка `Can't find variable: autoLabel` при рендере AI-панели. Причина известна: `autoLabel` объявлен внутри `if(tags?.length)`, а ниже используется снаружи для `activeCat`. Исправлять маленьким scoped patch, без переписывания AI-панели.

## Архитектура памяти

Два контура:

- пользовательское приватное облако: заметки, ai memory, напоминания;
- проектный кластер разработчика: баги, идеи, решения, промты, TODO, архитектура.

Для пользователей AI не должен становиться “Джарвисом”. Он ассистент, друг, планировщик, напоминалка и мягкий помощник мышления.

Для разработчика нужен отдельный рабочий кластер, из которого потом можно собирать MASTER/TODO/контекст проекта.

## Правило деплоя

1. Сравнить новый `incoming/indexN.html` с текущим `index.html`.
2. Выписать полезные слои.
3. Не брать регрессии: auth, AI, audio cleanup, Supabase, PWA, сохранение заметок.
4. Внести точечно через `apply_patch`.
5. Проверить inline JS, manifest, sw syntax.
6. Локально проверить маркеры.
7. Bump `sw.js` cache.
8. Commit.
9. Push.
10. Проверить GitHub Pages по маркерам и хэшу.
