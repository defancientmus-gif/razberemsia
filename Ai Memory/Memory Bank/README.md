# Memory Bank

Единая папка для всех файлов памяти проекта «Разберёмся».

## Правило

Все важные master-сейвы, сжатия контекста, проектные памяти, режимы Codex/Claude и будущие выгрузки анализатора блокнота складывать сюда.

Старые папки `Ai Memory/Master Modes/Codex` и `Ai Memory/Master Modes/Claude` остаются как режимы-источники, но каноническое хранилище памяти теперь здесь.

## Текущие файлы

- `CODEX_MASTER.md` — рабочий мастер-контекст Codex.
- `CLAUDE_MASTER.md` — мастер-контекст Claude.
- `CLAUDE_PROJECT_MASTER.md` — проектный master от Claude с подробным списком реализованного.
- `AI_MEMORY_ARCHITECTURE.md` — архитектура памяти AI.

## Будущие файлы

- `NOTEBOOK_AI_MEMORY.md` — память AI-блокнота после подключения анализатора.
- `PROJECT_MEMORY_LOG.md` — проектные заметки, решения, баги, идеи и промты из рабочего кластера.
- `USER_MEMORY_MODEL.md` — схема приватной пользовательской памяти.

## Принцип

Память не должна быть свалкой сырого текста. Нужны короткие, полезные, восстанавливаемые сжатия:

- что изменилось;
- почему это важно;
- какой файл/модуль связан;
- что делать следующим шагом;
- какие решения уже приняты;
- какие риски нельзя забыть.
