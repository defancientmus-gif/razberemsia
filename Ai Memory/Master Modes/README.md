# Master Modes

Папка для сохранённых мастер-режимов AI-партнёров проекта.

Цель: не смешивать роли Codex и Claude.

Каноническое хранилище памяти теперь находится в `Ai Memory/Memory Bank`.
Эта папка остаётся как источник режимов и история разделения ролей.

- `Codex/` — режимы для аккуратной инженерной работы, ревью, внедрения и деплоя.
- `Claude/` — режимы для сильной идейности, продуктовой архитектуры, концепций и вариантов.

Правило: Claude получает пространство для идей и архитектуры. Codex помогает, проверяет, дополняет, шлифует и внедряет аккуратно, не перетягивая проект на себя.
