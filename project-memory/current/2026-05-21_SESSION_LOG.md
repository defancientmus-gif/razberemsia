## Ключевые продуктовые решения

### Концепция — голосовой агент
**Главный сдвиг**: «Разберёмся» — не блокнот с ИИ, а **голосовой агент с памятью**, у которого есть блокнот.

Принцип:
```
Голос → агент понял намерение → выполнил действие → показал карточку «Вижу»
```

Кнопки и меню — fallback для тех кто хочет руками. Голос — основной путь.

### UI-принцип — «бабушка»
Целевой пользователь — человек который с трудом нажимает на кнопочки.
- Первый экран закрывает ВСЕ потребности
- Никаких меню без необходимости
- Одна большая кнопка микрофона
- Агент показывает что сделал — человек подтверждает

### Карточка «Вижу»
Когда агент выполняет команду — показывает всплывающую карточку:
```
╭──────────────────────────────╮
│  ✦  Вижу: напоминание        │
│  💧 Попить воду              │
│  В 15:42 · через 60 мин      │
╰──────────────────────────────╯
```
Карточка сама уходит через 3-4 секунды. Не модальная, не блокирует.

### Память агента
Хранить не переписку, а сжатый профиль пользователя:
```json
{
  "name": "Николай",
  "patterns": ["просыпается в 7:30", "пьёт таблетки в 8:00"],
  "health_notes": ["давление", "диабет 2 типа"],
  "preferences": ["говорит коротко"],
  "last_summary": "15 мая говорили про будильник и воду..."
}
```
После каждого разговора — агент сам сжимает и обновляет профиль. Не собирает заново.

### Intent-роутер (запланировано)
Расширить `parseVoiceReminder` до полноценного роутера:
```
SET_REMINDER  → push-уведомление
SET_ALARM     → нативный будильник (Android intent / iOS Clock)
CREATE_NOTE   → создать заметку
SLEEP_STATS   → показать график сна
QUESTION      → ответить текстом
FIND_DOCTOR   → медицинский навигатор
```

### Умный будильник (запланировано)
- Акселерометр (DeviceMotion API) — отслеживает движение во сне
- Классификация фаз сна по паттернам движения
- Окно пробуждения (напр. 6:50–7:30) — будит в лёгкой фазе
- Голосовая команда: «Поставь умный будильник на 7:30»

### Android будильник
- `intent://` URL → открывает нативные Часы с заполненным временем
- Пользователь нажимает ОК
- На iOS — открывает Часы (без предзаполнения, ограничение платформы)

## Медицина — важные решения

### НЕ медицинский советник
Отказались от модели «AI даёт советы по здоровью». Причины:
- Люди следуют советам даже с дисклеймером «я не врач»
- Юридическая ответственность
- Этика

### Медицинский навигатор ✓
```
· Найти врача нужной специальности рядом
· Рейтинг клиник (2ГИС, ПроДокторов API)
· Помочь сформулировать жалобы для приёма
  "Скажи что болит — составим список вопросов врачу"
· Напомнить о приёме, выписать лекарства в заметку
· Хранить историю болезней, анализов
· Напомнить выпить таблетки
```

### Vera Health
Пользователь предложил Vera Health как источник медданных.
**Решение**: Vera Health — закрытый коммерческий продукт, брать данные напрямую рискованно.
Альтернативы:
- Партнёрство с Vera Health (написать им)
- Открытые медбазы: МКБ-10, справочник Видаль, WHO
- Специализированный медпромпт (можно сейчас) с обязательным «обратитесь к врачу»

## Коммерческая модель — зафиксировать

- AI не должен уметь писать код, объяснять технологии — только функции приложения
- Специализированный ограниченный домен: заметки + напоминания + здоровье + навигация
- Аудитория 55+ — отдельная ценная ниша, мало конкурентов с голосовым UI
- Медицинский навигатор — потенциально отдельная монетизируемая фича
