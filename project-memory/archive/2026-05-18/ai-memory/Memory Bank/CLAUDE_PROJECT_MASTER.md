## Одна строка идеи

Ультраадаптивный чат «Разберёмся» учит человека пользоваться заметками, чатом, интернетом и AI через мягкие микроподсказки прямо внутри чат-заметки, подстраиваясь под уровень человека и помогая делать следующий понятный шаг.

## Суть продукта

`Разберёмся` — спокойный цифровой помощник и PWA-заметки для людей, которым тревожно, сложно или непонятно пользоваться современными цифровыми сервисами.

> Если человек чего-то не понимает — это нормально. Разберёмся.

Не школа, не курс, не «обучение для чайников». Ощущение — терпеливый человек рядом.

## Что сделано и работает (полный список на 2026-05-18)

### Инфраструктура
- Основной runtime — один файл `index.html`
- GitHub Pages из ветки `main`, корень `/razberemsia/`
- PWA через `manifest.json` и `sw.js` (cache `rz-v50`)
- PWA-иконки: `pwa-feather-180.png`, `pwa-feather-192.png`, `pwa-feather-512.png`
- Firebase/SMS убраны. Авторизация: Supabase email OTP → 6-значный код → сессия
- Данные синхронизируются через Supabase `public.user_state`
- Локальные заметки scoped по `user.id`, миграция при первом входе

### AI-цепочка
- 2026-05-18: первый живой AI-анализ: `index.html → smooth-processor → Claude → UI`
- Кнопка `✦ AI` в редакторе возвращает `summary`, `tags`, `actions`
- Модель: `claude-haiku-4-5-20251001`
- `ANTHROPIC_API_KEY` только в Supabase Secrets, не в клиенте
- Edge Function: `supabase/functions/ai/index.ts`, endpoint `smooth-processor`

### UI заметок — раздел «Заметки» (реализовано 2026-05-18)
- **Стеклянные папки**: 8 фиксированных папок-разделов с glassmorphism, ушком-табом, внутренним бликом
- **Иконки категорий**: 🏥 здоровье, 🛒 покупки, 👤 контакт, 📅 событие, 💡 идея, 🍽️ рецепт, 📍 адрес, 📝 заметка
- **Папка «Все»** — растянута на всю ширину, показывает общее число заметок
- **Сворачивание папок**: клик на заголовок «Разделы» — папки улетают вверх (`featherUp`), появляется компактная строка-peek с активным разделом. Разворачивание — прилетают вниз (`featherDown`). Состояние сохраняется в `localStorage`. Guard от двойного тапа.
- **Переключение список/сетка**: кнопка рядом с заголовком «Заметки». Анимация смены — капля (`dropReveal` через `clip-path`). В сетке карточки вылетают пружинно (`cardMorph`). Режим сохраняется в `localStorage`.
- **AI-теги на карточках**: до 2 тегов из `aiTags[]` отображаются пилюлями под заголовком

### AI-авто-категория (TAG_TO_CAT)
- ~60 тегов → 8 папок. Алгоритм голосования: побеждает папка с наибольшим числом тегов
- После `✦ AI` анализа категория применяется автоматически (только если пользователь не выбрал вручную)
- Под кнопкой категории — подсказка «✦ AI предложил» на 5 секунд
- `aiTags[]` и `aiSummary` сохраняются в объекте заметки
- `analyzeText()` (оффлайн) тоже использует `TAG_TO_CAT` — единая логика везде

### Голосовые и аудио-заметки
- Кнопка `🎤 Голосовая заметка` в шапке редактора
- При записи: пульсирующая кнопка + волна визуализация
- После остановки: расшифровка AI вставляется в текст, показывается блок `✦ Расшифровка AI`
- Если AI-панель открыта — автоматически перезапускает анализ с новым текстом
- Удержание кнопки «Новая заметка» на главном экране — голосовой ввод

### Календарь
- Glassmorphism попап: `backdrop-filter: blur(50px) saturate(2.2)`, белая рамка, блик
- Фроsted-оверлей: `backdrop-filter: blur(14px)` вместо чёрного
- Ручка-дёргалка вверху (iOS bottom sheet style)
- Дни: 46px, выходные в тёплом тоне, выбранный день со свечением
- Сегодня: `box-shadow` вокруг рамки
- Точки-заметки: 5px с золотым `glow`
- Кнопка «Готово»: стеклянная, акцентный текст

### Тёмная тема
- Реализована через CSS filter: `invert(1) hue-rotate(180deg)` на `html.dark`
- Плавный переход `transition: filter .35s ease`
- Изображения и canvas двойной инверт → выглядят нормально
- Переключатель: пункт «Тёмная тема» в меню (☰)
- Иконка меняется: луна / солнце
- Состояние сохраняется в `localStorage('rz_dark')`

### Остальной функционал
- Редактор заметки: undo/redo, автобуллеты, автонумерация, paste-в-список
- Голосовой ввод через Web Speech API в блокноте и редакторе
- Корзина, история правок за 7 дней, восстановление версий
- Чеклисты с галочками, swipe-удаление, поделиться
- Календарь-фильтр заметок по дате
- Экран «Что-то случилось?» — сценарии цифровой помощи
- Настройки: имя, аккаунт, выход
- PWA offline fallback

## Supabase Auth

Email OTP поток:
1. Пользователь вводит почту
2. `signInWithOtp({ email, options:{ shouldCreateUser:true } })`
3. Supabase отправляет 6-значный код
4. `verifyOtp({ email, token, type:'email' })`
5. `enterUser(user)` → загрузка `user_state` → `loadAll()`

Публичные ключи в клиенте допустимы:
```js
const SUPABASE_URL='https://izvwgyudjbxlixzrgpuv.supabase.co';
const SUPABASE_ANON_KEY='sb_publishable_YtwehFnevo4R3UpmOnTTXQ_j4PQY21D';
```


```js
const SUPABASE_EDGE_URL='https://izvwgyudjbxlixzrgpuv.supabase.co/functions/v1/smooth-processor';
```

Запрос: `{ action:'analyze', payload:{ text } }` + `Authorization: Bearer <token>`

API key: только в Supabase Secrets, никогда в клиенте.
