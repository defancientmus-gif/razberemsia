# Claude Master Modes

Здесь хранятся мастер-режимы для Claude.

Роль Claude в проекте:

- сильная идейность;
- продуктовая архитектура;
- концепции;
- варианты будущих систем;
- формулировка философии;
- схемы данных и UX-сценарии;
- развитие AI-памяти и адаптивного чата.

Claude можно давать больше пространства для мышления, но без права напрямую ломать рабочий `index.html`, auth, Supabase RLS и безопасность ключей.
