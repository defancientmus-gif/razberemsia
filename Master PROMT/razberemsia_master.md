## Миссия проекта

`Разберёмся` — спокойный цифровой помощник для людей, которые испытывают стресс, страх или непонимание при взаимодействии с современными технологиями.

Главный принцип:

> Если человек чего-то не понимает — это нормально. Разберёмся.

Это не курс и не школа. Это человек рядом, который помогает без давления и без стыда.

## Auth flow

Текущий вход:

1. `sendEmailLink()` отправляет код через `signInWithOtp`.
2. UI переходит на `step-code`.
3. `verifyOtpCode()` проверяет код через `verifyOtp`.
4. После успешной сессии вызывается `enterUser()`.
5. Данные загружаются из Supabase и приложение открывается.

Не путать с предыдущим magic link. Сейчас основной сценарий — 6-значный код.

## Правила работы

- Не создавать новые HTML-файлы как рабочую версию.
- Не переименовывать `index.html`.
- Не возвращать Firebase/SMS/dev-вход.
- Не отключать RLS.
- Не переписывать всё приложение без необходимости.
- При правках PWA/JS повышать cache name в `sw.js`.
- Если пользователь просит только промты/документы, не менять код.
