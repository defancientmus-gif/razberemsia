## 🔥 СЛЕДУЮЩАЯ СЕССИЯ v3.95 — ЧТО ДЕЛАЕМ

### 🎨 Liquid Glass стиль — применить ко всему интерфейсу

**Концепция утверждена.** Отталкиваемся от голосовой кнопки-пузыря.

Принципы:
- Мягко, ненавязчиво — не кричащий глянец, а воздушное стекло
- Все карточки, шторки, кнопки — в едином liquid glass духе
- Фоны: полупрозрачные с блюром, блики сверху-слева, тень снизу
- Цвета: тёплый кремовый фон + шалфейный акцент + белые блики

Что переработать:
- [ ] Карточки заметок — glass стиль вместо глухого белого
- [ ] Кнопки категорий (чипы) — glass пилюли
- [ ] Шторка редактирования заметки — как шторка ввода
- [ ] Кнопки «Изменить» / «Удалить» на карточке — glass стиль
- [ ] Экран «Что случилось?» — карточки в glass стиле
- [ ] Auth экран — glass card уже есть, доработать блики

### 📝 Единый компонент заметки — 3 точки входа

**Архитектурное решение утверждено.**

Одна функция `openNoteSheet(note, index)` — открывает шторку редактирования.
Вызывается из:
1. Чат (home feed) — нажатие на bubble-сообщение
2. Раздел Заметки — нажатие на карточку
3. Шторка ввода — после сохранения (опционально)

Что сделать:
- [ ] Вынести `openNoteSheet` как единую функцию
- [ ] Bubble-сообщения в чате — кликабельны, открывают редактирование
- [ ] Раздел Заметки — карточки открывают ту же шторку (не отдельный editNote)
- [ ] Внутри шторки: заголовок, тело, категория, напоминание, кнопки закрепить/избранное

### 🔙 Нижняя панель главного экрана — финальный вид

```
[  поле-пузырь "Что на уме..."  ] [ 🫧 голос ]
```

- Поле: liquid glass пилюля, ~70% ширины
- Голос: пузырь 52px с туманчиком, парит
- Тап на поле → шторка ввода раскрывается снизу вверх
- Тап на голос → сразу запись → автосохранение

## 🎨 ДИЗАЙН-СИСТЕМА (утверждена в сессии 14.05.2026)

### Liquid Glass — принципы

```css
/* Базовый glass эффект */
background:
  radial-gradient(circle at 30% 28%, rgba(255,255,255,0.5) 0%, transparent 40%),
  rgba(255,255,255,0.18);
border: 1px solid rgba(255,255,255,0.5);
backdrop-filter: blur(14px) saturate(1.3);
box-shadow:
  inset 0 2px 5px rgba(255,255,255,0.55),
  0 8px 28px rgba(100,160,130,0.12);

/* Блик (::before) */
top: 14px; left: 18px;
width: 26px; height: 18px;
background: radial-gradient(ellipse, rgba(255,255,255,0.75), transparent);
transform: rotate(-30deg);
filter: blur(1px);
```

### Голосовая кнопка
- Размер: 52px (нижняя панель), 108px (полноэкранный режим)
- Форма: идеально круглая (border-radius: 50%)
- В покое: зелёный туман, парит (анимация float 4-5s)
- При записи: красноватый туман, пульсирует
- Подпись: «Нажмите, чтобы говорить» / «Говорите… нажмите чтобы остановить»

### Цветовая палитра
```
--sage: #7a9e7e        /* Основной акцент */
--sage-d: #4a6e4e      /* Тёмный акцент */
--cream: #f5f0e8       /* Фон */
--warm: #ede5d8        /* Тёплый фон */
--stone: #c4b8a8       /* Нейтральный */
--text: #1c1c1e        /* Основной текст */
--text-m: #3a3a3c      /* Средний текст */
--text-l: #6e6e73      /* Лёгкий текст */
--rose: #c0504a        /* Акцент опасности */
--gold: #b8883a        /* Золотой акцент */
```

### Шрифты
- Основной: `-apple-system, BlinkMacSystemFont, 'SF Pro Display'`
- Логотип и заголовки: `'Playfair Display', serif`
- Размеры: базовый 17px, для пожилых чуть крупнее
