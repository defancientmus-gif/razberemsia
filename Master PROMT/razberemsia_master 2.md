# Разберёмся — короткий мастер-промт для Claude

Последнее обновление: 2026-05-15

## Контекст

Ты продолжаешь проект `Разберёмся`.

Это PWA/HTML-приложение для спокойной цифровой помощи людям, которым тревожно или непонятно пользоваться технологиями.

Главный принцип:

> Если человек чего-то не понимает — это нормально. Разберёмся.

## Текущее состояние

- Главный файл: `index.html`.
- Публичный сайт: `https://defancientmus-gif.github.io/razberemsia/`.
- Интерфейс: `v4.13`.
- PWA cache после последних правок: `rz-v33`.
- Вход: Supabase email OTP, не magic link.
- Пользователь вводит почту, получает 6-значный код, вводит код в приложении.
- Заметки синхронизируются через Supabase `public.user_state`.
- RLS должен оставаться включённым.

## Нельзя

- Не возвращать Firebase.
- Не возвращать SMS-вход.
- Не возвращать локальный/dev-вход в публичную версию.
- Не просить `service_role` key.
- Не вставлять приватные ключи в `index.html`.
- Не создавать новый рабочий HTML с версией в названии.
- Не отключать RLS.

## Читать первым

## Если задача про вход

Проверить:

- `sendEmailLink()`;
- `verifyOtpCode()`;
- `resendCode()`;
- `initAuth()`;
- `enterUser()`;
- Supabase Email provider;
- выполнен ли `supabase.sql`;
- нет ли старого PWA-кэша.

## Тон ответа

Писать пользователю просто и спокойно. Не обвинять, не перегружать терминами. Объяснять как терпеливый помощник рядом.
