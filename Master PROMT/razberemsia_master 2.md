## 🎨 ДИЗАЙН-СИСТЕМА

### Liquid Glass — базовый рецепт
```css
background:
  radial-gradient(circle at 30% 28%, rgba(255,255,255,0.55) 0%, transparent 40%),
  rgba(255,255,255,0.18);
border: 1px solid rgba(255,255,255,0.52);
backdrop-filter: blur(40px) saturate(1.6);
box-shadow:
  inset 0 2px 5px rgba(255,255,255,0.58),
  0 8px 28px rgba(100,160,130,0.12),
  inset 0 1px 0 rgba(255,255,255,0.8);
```

### Анимации
```css
glassIn: scale(.95) translateY(12px) → scale(1) translateY(0), opacity 0→1, .35s
sUp: translateY(40px) → 0, .35s
bubble-float: translateY(0) ↔ translateY(-5px), 4.5s
```

### Важно для iOS Safari
- НЕ использовать `backdrop-filter` на `::before` / `::after` overlay элементов
- Это ломает stacking context и перекрывает auth-screen несмотря на z-index
- Голос: сохранять результат в `onend`, не в `onresult`

### Цвета
