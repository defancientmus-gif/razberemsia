## Терминология — Раздел «Заметки»

```
┌─────────────────────────────────────┐
│           📱 Приложение             │
│  ┌──────┐ ┌──────┐ ┌──────┐        │
│  │Главная│ │ЗАМЕТКИ│ │Поиск │       │  ← табы внизу
│  └──────┘ └──────┘ └──────┘        │
└─────────────────────────────────────┘

         ↓ открываем ЗАМЕТКИ

┌─────────────────────────────────────┐
│  Заметки          [+ новая]         │  ← заголовок экрана
│─────────────────────────────────────│
│                                     │
│  РАЗДЕЛЫ                            │  ← блок (создаёт пользователь)
│  ┌─────────────┐  ┌─────────────┐   │
│  │  Финансы    │  │  Здоровье   │   │  ← Раздел
│  └─────────────┘  └─────────────┘   │
│                                     │
│  ПАПКИ                    авт.      │  ← блок (создаёт агент)
│  ┌─────────────┐  ┌─────────────┐   │
│  │   врач      │  │  покупки    │   │  ← Папка
│  └─────────────┘  └─────────────┘   │
│                                     │
└─────────────────────────────────────┘

         ↓ заходим в Раздел «Здоровье»

┌─────────────────────────────────────┐
│  Заметки › Здоровье                 │  ← хлебные крошки
│─────────────────────────────────────│
│  ┌───────────────────────────────┐  │
│  │ Выпил витамины                │  │  ← Заметка
│  │ вчера · #витамины  #здоровье  │  │     └── теги (чипы)
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ Запись к врачу 5 июня  🔔     │  │  ← Заметка с напоминанием
│  │ #врач                         │  │
│  └───────────────────────────────┘  │
└─────────────────────────────────────┘
```

---

### Коротко словами

| Слово | Что это | Кто создаёт |
|-------|---------|-------------|
| **Заметка** | одна запись | пользователь / агент |
| **Тег** | метка на заметке (#витамины) | агент при анализе |
| **Папка** | временная группа по теме | агент автоматически |
| **Раздел** | постоянная категория | пользователь вручную |
| **Заметки** | таб / весь раздел приложения | — |

### Главное отличие Папки от Раздела

```
Папка  →  временная  →  агент разложил, потом разберёшь
Раздел →  постоянная →  ты сам решил что это важная категория
```
