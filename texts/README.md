# texts

Единая папка проектного контекста. Если Женя не знает, какой файл дать Claude или Codex, начинать отсюда.

## Быстрый вход

1. `CLAUDE.md` в корне - правила поведения инженера.
2. `texts/README.md` - эта карта.
3. `texts/ROUTER.md` - какие файлы читать под задачу.
4. `texts/SNAPSHOT.md` - текущее фактическое состояние.
5. `texts/NEXT.md` - ближайшая работа и последние решения.

Не читать весь архив и все идеи подряд. Сначала маршрут, потом только нужные файлы.

## Активные файлы

| Файл | Для чего |
| --- | --- |
| `ROUTER.md` | контекстный маршрутизатор: код, дизайн, промпты, план, память |
| `SNAPSHOT.md` | фактическое состояние деплоя, кэша, GitHub, Supabase |
| `NEXT.md` | что сделано последним и что делать дальше |
| `CONTEXT.md` | продукт, аудитория, философия, границы |
| `STATUS.md` | что работает, что сломано, что проверить |
| `RULES.md` | правила правок, PWA, Supabase, деплоя |
| `TEST_GRID.md` | жизненные сценарии проверки перед/после деплоя |
| `UI_PHILOSOPHY.md` | визуальный закон проекта |
| `MASTER_PROMPT.md` | стартовый промпт для Claude |
| `PROMPTS.md` | промпты и AI-actions продукта |
| `TERMINOLOGY.md` | краткие термины для папок, разделов, тегов |

## Идеи

| Файл | Когда читать |
| --- | --- |
| `IDEAS_NEAR_TERM.md` | ближайшие этапы и идеи, которые можно брать в работу |
| `IDEAS_BETA_DELIGHTERS.md` | необычные фичи для беты |
| `IDEAS_FUTURE.md` | дальняя перспектива |
| `IDEAS_DONE_OR_DORMANT.md` | уже делали, могло заснуть, проверить перед повторной реализацией |

## Архив

`texts/archive/` - старые документы и сырые первоисточники. Это не источник правды.

Правило архива: если из старого файла нужен смысл, перенести его коротко в активный файл. Не тащить старый документ обратно в работу целиком.
