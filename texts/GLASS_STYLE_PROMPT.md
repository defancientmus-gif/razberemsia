# Промт визуального стиля — «парящие стеклянно-керамические карточки»

> Переносимый промт. Можно вставить в любую AI-сессию или отдать дизайнеру —
> описывает ТОЛЬКО графику (материал, свет, форма, движение), без продуктовой философии.
> Продуктовая философия — в [[UI_PHILOSOPHY.md]] и [[TECH_PROMPT.md]].
> Эталонные источники — `index.html`: `.hf-card` (превью в ленте), `.sheet` (открытая заметка,
> в коде буквально стоит комментарий «Liquid glass»), `.drill-note-row`/`.shelf-row` (списки).

## Два уровня стекла — не путать

В коде осознанно два разных уровня прозрачности стекла (комментарии разработчика подтверждают это):

1. **Превью в ленте (`.hf-card`)** — «стеклянная капсула»: `blur(12px) brightness(1.04)`,
   заметная, но умеренная — стекло должно быть видно, но текст поверх остаётся чётким.
2. **Открытая заметка (`.sheet`)** — настоящий **Liquid glass**: `blur(20px)`, ещё выше
   прозрачность фона (`oklch(0.98 0.004 215 / 0.20)` — почти невидимый сам по себе),
   виднее то, что позади. Дословный комментарий в исходнике:
   *«Liquid glass: высокая прозрачность + умеренный blur = видно сквозь, текст чёткий»*.

Чем крупнее/центральнее элемент — тем гуще блюр и тем прозрачнее фон. Мелкие строки-списки
(`.drill-note-row`, `.shelf-row`) блюра вообще не используют — только градиент+тень
(дешевле по GPU, их много на экране одновременно).

---

## Образ одной фразой

Карточки — не плоские прямоугольники и не пластик. Это **тонкие керамические стёклышки,
подсвеченные сверху**, будто лежат на облаке и чуть приподняты над фоном. Не блестят,
не переливаются — матовые, мягкие, «на ощупь тёплые». Референс: iOS-шиты, Bear Notes,
Things 3 — НЕ Material Design (никакого ripple/elevation/резких теней).

## Материал: из чего сделана карточка

### Уровень 1 — превью/список (без blur, дешёвый по GPU)

Три слоя дают эффект стекла — **все три обязательны, ни один не даёт эффект в одиночку**:

1. **Фон** — не сплошной цвет, а едва заметный диагональный градиент (свет падает сверху-слева):
   ```css
   background: linear-gradient(158deg, oklch(1 0 0 / .82) 0%, oklch(0.965 0.012 210 / .72) 100%);
   ```
2. **Кромка — завёрнутый край, без рамки.** Кольца 1px вокруг стекла нет: толщину даёт
   свет изнутри, а не обводка (Женя 19.10: «нужны ли эти рамочки вокруг граней… завернуть
   и слегонца размыть», выбрал «Завёрнутый край»; канон штата, первым — Гили c67d1f8):
   ```css
   border: 0;
   ```
3. **Тень — свет изнутри + парение снаружи**, это ключевой трюк:
   ```css
   box-shadow:
     inset 0 1.5px 1px -.5px oklch(1 0 0 / .95),  /* тонкий свет сверху = толщина стекла */
     inset 0 0 22px oklch(1 0 0 / .34),           /* мягкое свечение по краю внутрь = матовость */
     inset 0 -12px 20px -16px oklch(1 0 0 / .5),  /* подсвет снизу = край завёрнут */
     0 4px 13px -3px oklch(0.32 0.035 210 / .11); /* внешняя тень = отрыв от фона, едва видна */
   ```
   Внешняя тень **холодного оттенка** (не чёрная), низкая (offset маленький, blur средний,
   spread отрицательный), почти прозрачная. Это даёт «парение», а не «предмет лежит».

Радиус зависит от размера: **20px** (карточка заметки на десктопе/крупный экран),
**18px** (обычная карточка/строка-полка), **16px** (сетка/мелкие), **28px** (bottom sheet).
Никогда меньше 12px — острые углы читаются как «Windows 95», не как керамика.

### Тёмная тема — не инверсия, а другой материал
Не «тёмный градиент», а **однородное тёмное стекло с лёгким backdrop-blur**:
```css
background: oklch(1 0 0 / 0.07);
border: 0;
box-shadow:
  inset 0 1.5px 1px -.5px oklch(1 0 0 / 0.22),
  inset 0 0 18px oklch(1 0 0 / 0.06),
  inset 0 -10px 16px -14px oklch(1 0 0 / 0.10),
  0 2px 10px oklch(0 0 0 / 0.30);
backdrop-filter: blur(8px); -webkit-backdrop-filter: blur(8px);
```
Завёрнутый край остаётся и здесь, только свет изнутри тише (на тёмном белое .34 читается
как молочная плёнка), внешняя тень становится чёрной (на чёрном фоне холодная не работает).

### Уровень 2 — превью в ленте и открытая заметка (настоящий backdrop-filter)

Здесь стекло не имитируется градиентом, а **реально размывает то, что под карточкой**.
Дороже по GPU — поэтому применяется только к крупным/немногочисленным на экране элементам.

**Превью заметки в ленте** (`.hf-card`) — «стеклянная капсула», умеренный блюр:
```css
background:
  linear-gradient(155deg,
    oklch(1 0 0 / 0.62) 0%,
    oklch(0.97 0.010 215 / 0.38) 55%,
    oklch(0.94 0.015 220 / 0.28) 100%);
backdrop-filter: blur(12px) brightness(1.04);
-webkit-backdrop-filter: blur(12px) brightness(1.04);
border: 0;                               /* завёрнутый край, без кольца */
box-shadow:
  inset 0 1.5px 1px -.5px oklch(1 0 0 / 0.95), /* тонкий свет сверху */
  inset 0 0 22px oklch(1 0 0 / 0.34),          /* свечение по краю = матовость */
  inset 0 -12px 20px -16px oklch(1 0 0 / 0.5), /* подсвет снизу = край завёрнут */
  0 2px 8px oklch(0.35 0.08 210 / 0.06),
  0 8px 24px oklch(0.35 0.08 210 / 0.08);  /* «тень парения» — мягкий ореол снизу */
border-radius: 16px;
```
Трёхстопный градиент (не два, а три оттенка) даёт более живой, не «плоский» блик —
свет как будто действительно скользит по изогнутой поверхности.

**Открытая заметка / bottom sheet** (`.sheet`) — максимальная плотность эффекта, самый
крупный и самый «стеклянный» элемент интерфейса:
```css
background:
  radial-gradient(ellipse 120% 40% at 50% 0%, oklch(1 0 0 / 0.18), transparent 60%),
  oklch(0.98 0.004 215 / 0.20);   /* фон почти прозрачный сам по себе */
backdrop-filter: blur(20px);
-webkit-backdrop-filter: blur(20px);
border-radius: 28px;
border: 0;   /* и внутреннего кольца inset 0 0 0 1px тоже нет — это та же рамка */
box-shadow:
  0 18px 70px -28px oklch(0 0 0 / 0.28),
  0 4px 24px -16px oklch(0.22 0.05 210 / 0.18),
  inset 0 1.5px 1px -.5px oklch(1 0 0 / 0.95),
  inset 0 0 22px oklch(1 0 0 / 0.34),
  inset 0 -12px 20px -16px oklch(1 0 0 / 0.5);
```
Радиальный градиент сверху (не диагональный линейный, как у мелких карточек) — свет
идёт из одной точки над листом, будто заметка освещена сверху как страница на столе.
Появление — `sheetRise .32s cubic-bezier(.22,1,.36,1)`: `scale(.92) translateY(10px)` →
`scale(1) translateY(0)`, без overshoot (тот же закон, что и у мелких карточек).

**Важная деталь про `backdrop-filter` и производительность**: убирать его на элементах,
которые одновременно двигаются через бесконечную `transform`-анимацию (плавающая кнопка
агента) — блюр на движущемся слое пересчитывается каждый кадр и греет телефон. Тогда эффект
стекла держат только градиент+тень (Уровень 1), без blur.

## Свет и цвет — правила

- Все цвета — **только `oklch()`**, никогда hex/rgb. Это не эстетика, а инженерия:
  oklch даёт предсказуемую светлоту при смешивании альфа-каналов между темами.
- Оттенок почти всегда **холодный синевато-серый** (`210–220` по hue) — «облачный», не тёплый серый.
- Блик (`inset 0 1.5px 1px -.5px`) — **всегда чуть белее/светлее фона самой карточки**, имитирует
  скос стекла, ловящий свет сверху; вместе со свечением по краю и подсветом снизу заменяет рамку.
- Внешняя тень — **никогда чёрная в лоб** (`oklch(0 0 0 / …)` слишком резко читается);
  в светлой теме используем чуть тонированную тень `oklch(0.32 0.035 210 / …)` — тень
  того же холодного оттенка, что и сама сцена, поэтому карточка не «прилипает» визуально.
- **Никогда** `box-shadow` с spread больше 12px или явно видимая тень — если тень
  заметна глазом без прищура, она слишком сильная. Керамика лежит низко над столом,
  не парит на полметра.

## Форма и глубина — иерархия слоёв

Порядок «стекла над стеклом» (каждый следующий слой немного светлее/ближе):
```
фон приложения (самый темный/дальний)
  → карточка обычная (.drill-note-row, .shelf-row)
    → карточка активная/поднятая (.shelf-master — на 1-2% светлее, тень чуть глубже)
      → всплывающая карточка агента / bottom sheet (backdrop-filter blur(12px), самая близкая)
```
Не делать все карточки одним и тем же уровнем стекла — глубина считывается только
через тонкую разницу прозрачности между соседними слоями (2-4% альфы, не больше).

## Движение — «мягкое перо», не пружина

Карточка не выскакивает и не пружинит — она **проявляется, будто лист опускается на воду**:
```css
@keyframes folderIn {
  from { opacity: 0; transform: translateY(10px) scale(.96); }
  to   { opacity: 1; transform: translateY(0) scale(1); }
}
.card { animation: folderIn .28s cubic-bezier(.22,1,.36,1) both; }
```
- Кривая **всегда** `cubic-bezier(.22,1,.36,1)` — быстрый старт, перьевое приземление.
  Никаких `back`/`elastic`/overshoot (`scale` не должен превышать 1.0 в процессе анимации).
- Длительность **.28–.32s** для появления, **.12–.16s** для press/active.
- Списки — стаггер **.04s** между карточками (не больше, иначе тормозной эффект).
- Нажатие: только `transform: scale(.98); transition: transform .12s` — никакого ripple,
  никакого изменения фона на active.
- **Анимировать только `transform` и `opacity`.** Никогда `box-shadow`/`filter`/`backdrop-filter`
  внутри `@keyframes` — перерисовка на каждый кадр греет телефон (было замерено на проде).

## Что убивает эффект (проверено на практике — реально ломали)

- ❌ Сплошной однотонный фон карточки без градиента — сразу выглядит «плоско», не стеклянно.
- ❌ Тень без `inset`-блика — без него нет ощущения толщины стекла, просто плоская плашка с тенью.
- ❌ Рамка `border: 1px solid` белым или кольцо `inset 0 0 0 1px` вокруг стекла — читается как
    обводка, не как толщина (Женя 19.10 «нужны ли эти рамочки»). Край даёт свет изнутри.
- ❌ Чёрная тень без тонировки в цвет сцены — читается как Material Design/Bootstrap.
- ❌ `border-radius` < 12px — острые углы = не керамика.
- ❌ Overshoot/пружина в анимации появления — читается как баг, не как «лёгкость».
- ❌ `backdrop-filter` на элементе, который одновременно двигается (`transform` в keyframes) —
    блюр на движущемся слое перегревает GPU на телефоне.
- ❌ Декоративные `::before`/`::after` «для блика» — эффект уже есть в градиенте+inset,
    лишний слой не нужен и не согласован с продуктовым правилом «ничего лишнего».

## Готовый копипаст — базовая карточка (light + dark)

```css
.glass-card{
  background: linear-gradient(158deg, oklch(1 0 0 / .82) 0%, oklch(0.965 0.012 210 / .72) 100%);
  border: 0;
  border-radius: 18px;
  box-shadow:
    inset 0 1.5px 1px -.5px oklch(1 0 0 / .95),
    inset 0 0 22px oklch(1 0 0 / .34),
    inset 0 -12px 20px -16px oklch(1 0 0 / .5),
    0 4px 13px -3px oklch(0.32 0.035 210 / .11);
  transition: transform .12s;
}
.glass-card:active{ transform: scale(.98); }
.glass-card.appear{ animation: cardIn .28s cubic-bezier(.22,1,.36,1) both; }

@keyframes cardIn{
  from{ opacity:0; transform: translateY(10px) scale(.96); }
  to  { opacity:1; transform: translateY(0) scale(1); }
}

html.dark .glass-card{
  background: oklch(1 0 0 / 0.07);
  border: 0;
  box-shadow:
    inset 0 1.5px 1px -.5px oklch(1 0 0 / 0.22),
    inset 0 0 18px oklch(1 0 0 / 0.06),
    inset 0 -10px 16px -14px oklch(1 0 0 / 0.10),
    0 2px 10px oklch(0 0 0 / 0.30);
  backdrop-filter: blur(8px); -webkit-backdrop-filter: blur(8px);
}
```

Переносится дословно в любой новый проект (например БУ.шка) — единственное что меняется
между проектами — hue в oklch (у «Разберёмся» 210-220, холодный синий; для другого продукта
можно сдвинуть hue, сохранив структуру градиент+inset+внешняя тень).

## Готовый копипаст — «настоящее» стекло (превью/открытая карточка, с blur)

```css
.glass-preview{ /* аналог .hf-card — превью в ленте */
  background:
    linear-gradient(155deg, oklch(1 0 0 / 0.62) 0%, oklch(0.97 0.010 215 / 0.38) 55%, oklch(0.94 0.015 220 / 0.28) 100%);
  backdrop-filter: blur(12px) brightness(1.04);
  -webkit-backdrop-filter: blur(12px) brightness(1.04);
  border: 0;
  box-shadow:
    inset 0 1.5px 1px -.5px oklch(1 0 0 / 0.95),
    inset 0 0 22px oklch(1 0 0 / 0.34),
    inset 0 -12px 20px -16px oklch(1 0 0 / 0.5),
    0 2px 8px oklch(0.35 0.08 210 / 0.06),
    0 8px 24px oklch(0.35 0.08 210 / 0.08);
  border-radius: 16px;
}

.glass-sheet{ /* аналог .sheet — открытая карточка, максимум эффекта */
  background:
    radial-gradient(ellipse 120% 40% at 50% 0%, oklch(1 0 0 / 0.18), transparent 60%),
    oklch(0.98 0.004 215 / 0.20);
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
  border-radius: 28px;
  border: 0;
  box-shadow:
    0 18px 70px -28px oklch(0 0 0 / 0.28),
    0 4px 24px -16px oklch(0.22 0.05 210 / 0.18),
    inset 0 1.5px 1px -.5px oklch(1 0 0 / 0.95),
    inset 0 0 22px oklch(1 0 0 / 0.34),
    inset 0 -12px 20px -16px oklch(1 0 0 / 0.5);
  animation: sheetRise .32s cubic-bezier(.22,1,.36,1);
}
@keyframes sheetRise{
  from{ opacity:0; transform:scale(.92) translateY(10px); }
  60% { opacity:1; }
  to  { opacity:1; transform:scale(1) translateY(0); }
}
```

Правило выбора: если элементов на экране много и они мелкие/списочные →
Уровень 1 (без blur). Если элемент один/крупный/центральный (превью-лента, открытая
заметка, модалка) → Уровень 2 (с blur). Не давать `backdrop-filter` элементу, который
одновременно бесконечно анимируется через `transform` — грамм GPU того не стоит.

## Готовые CSS-токены проекта (можно унести как есть)

В `index.html` уже есть `:root` со стеклянными переменными — не изобретать заново:
```css
--glass-bg: oklch(0.97 0.004 225 / 0.52);
--glass-bd: oklch(0.90 0.012 225 / 0.5);
--fog:      oklch(0.91 0.011 212);      /* базовый тон тумана/сцены = тон фона */
--fog-72:   oklch(0.91 0.011 212 / 0.72);
--fog-42:   oklch(0.91 0.011 212 / 0.42);
--fog-20:   oklch(0.91 0.011 212 / 0.20);
```
Тёмная тема переключается классом `html.dark` (не `prefers-color-scheme` — это осознанно,
чтобы переключение темы управлялось в приложении, а не системными настройками телефона),
и в дарк-теме `--fog` меняется на `#000` — те же переменные, другое базовое значение.

Связано: [[UI_PHILOSOPHY.md]] (продуктовые правила «что никогда»), [[feedback_animation_language]] (память — почему без overshoot), [[TECH_PROMPT.md]] (весь переносимый промт системы).
