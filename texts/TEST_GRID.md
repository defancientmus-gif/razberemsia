# Test Grid

Тестовая сетка - короткий набор жизненных сценариев, которые надо проходить после заметных правок. Цель не "проверить всё", а быстро поймать регрессии в самых дорогих местах: заметки, агент, синхрон, PWA, напоминания.

## Когда запускать

- Перед деплоем: авто-сетка.
- После деплоя: проверить `β rz-v...` в шапке и 2-3 быстрых сценария.
- После правок агента, синка, сохранения, PWA или заметок: вся базовая сетка.

## Авто-сетка для Codex

Команды:

```bash
node --check js/app.js
git diff --check
node scripts/smoke-agent-router.mjs
```

Что покрывает:

| Сценарий | Ожидание |
| --- | --- |
| `запиши купить молоко` | Router profile `none` |
| `напомни купить фильтры завтра` | Router profile `none` |
| `напомни про то, что я хотел купить` | Router profile `notes` |
| `напомни о ней завтра` | Router profile `notes` |
| `найди про страховку` | Router profile `notes` |
| `разбери эту заметку` | Router profile `notes` |
| `прочитай последнюю заметку` | Router profile `notes` |
| `расскажи последнюю заметку` | Router profile `notes` |
| `удали это` | Router profile `notes` |
| `что у меня сегодня` | Router profile `deep` |
| `составь планы по заметкам` | Router profile `deep` |

Если авто-сетка падает, не деплоить, пока причина не понятна.

## Живая сетка для пользователя

Проходить руками в PWA после обновления.

| N | Действие | Что должно быть |
| --- | --- | --- |
| 1 | Посмотреть шапку | Видно свежий `β rz-v...` |
| 2 | `Запиши купить пену для мытья Xiaomi` | Заметка создана без уточнений |
| 3 | Нажать `Открыть заметку` в карточке агента | Открывается именно созданная заметка |
| 4 | `Напомни завтра оплатить интернет` | Создается напоминание на завтра |
| 5 | `Найди про страховку` | Открывается поиск/результаты по страховке |
| 6 | Открыть заметку и сказать `Разбери эту заметку` | Агент работает с текущей заметкой |
| 7 | `Что у меня сегодня?` | Агент делает сводку, а не создает заметку |
| 8 | `Напомни про то, что я хотел купить` | Агент ищет контекст в заметках, а не создаёт пустое напоминание |
| 9 | Создать заметку с тегом `идея` | Она появляется во `Входящие` |
| 10 | Создать заметку на Mac | Она появляется на телефоне/Windows через Realtime, fallback-polling или ручное обновление |
| 11 | Свайпнуть заметку на удаление | Заметка уходит в корзину и может быть восстановлена |

## Норма поведения агента

- `запиши`, `запомни`, `напомни` - действует без лишних вопросов.
- `найди`, `разбери`, `прочитай`, `удали` - использует заметки.
- `что у меня`, `сводка`, `план` - использует глубокий контекст.
- Уточняющий вопрос - только один и только если без него можно сделать не то.

## Что пока проверяет только человек

- Реальный голос на iPhone.
- Push-уведомления, когда PWA закрыта.
- Синхрон между Mac, iPhone и Windows как реальными устройствами.
- Ощущение дизайна руками.
- Home Screen PWA в Safari.
