### rz-v407 (2026-07-08) — фикс синхронизации между устройствами

Женя сообщил: заметки не синхронятся ни в одну сторону, даже после перезапуска приложения.
Проверка через `supabase db query --linked` (RLS на `user_state` в порядке, свежие данные
реально доходят до облака) показала: `saveCloudNow()` пушил в облако **сырой локальный
срез** заметок без сверки с тем, что там уже лежит. Если устройство A только что сохранило
новую заметку, а устройство B ещё не успело её подтянуть (pull) и в этот момент делает
любое своё сохранение — B перезаписывает в облаке заметку от A. Это гонка, а не разовый сбой,
поэтому «не появляется даже после перезапуска» — оба устройства могли клобберить друг друга.

Правки в `js/app.js`:
- `saveCloudNow()` — перед upsert подтягивает свежие `notes`/`trash` из облака и мёржит
  (`_mergeNoteArrays`/`_mergeTrashArrays`), вместо слепой перезаписи.
- `_pullCloudIfStale()` — ошибки больше не тонут молча (`catch(_){}` → `console.warn`).
- `_getLocalSyncedAt`/`_setLocalSyncedAt` — ключ синхро-метки привязан к аккаунту
  (`scopedKey`), раньше был общий на всё устройство независимо от того, кто залогинен.
- Попутно: `deploy.sh` искал в SNAPSHOT.md строку-метку деплоя, но такой строки не было —
  правки молча не применялись с 16 июня. Строка добавлена выше.

**Проверить на живых устройствах:** создать заметку на телефоне, подождать ~10с, убедиться
что появилась на ПК без перезагрузки — и наоборот.

### rz-v409 (2026-07-18) — самозаточка v1: локальный классификатор тегов

Первое воплощение курса «самозатачивающиеся алгоритмы» (см. `texts/SELF_TUNING.md`):
ИИ не работает вместо алгоритма — ИИ перетачивает правила алгоритма.

**Клиент (`js/app.js`):**
- Правила = данные: `rz_tag_rules` в localStorage `{tags:{"тег":{kw:[...]}},updatedAt}`. v1 живёт на устройстве (без синхронизации — каждое устройство затачивается само).
- `_localClassify(text)` — теги по словарю ключевых слов, без сети. Уверенность: ≥2 попаданий, или 1 на заметке ≤60 символов.
- `_smartAnalyze(text)` — гейт авто-анализа: короткая простая заметка (≤80 симв., без переносов) + уверенный классификатор → теги локально, `analyze` НЕ зовётся. Иначе — полный разбор как раньше. `aiCache` при локальной разметке не пишется — ручной клик на «анализ» всегда даёт полный ИИ.
- Каждый полный ИИ-разбор пишет обучающий пример `rz_tag_examples` (текст 140 симв. + теги, максимум 60 записей).
- `_maybeSharpenTagRules()` — фоном через 9с после входа, раз за сессию: нет правил + ≥20 размеченных заметок → стартовая генерация словаря из существующих заметок (один запрос за жизнь устройства); правила есть + ≥30 новых примеров (или ≥7 дней и ≥8 примеров) → переточка одним запросом, примеры очищаются.

**Edge (`index.ts`):** action `tune_rules` — промпт «оптимизатор правил», строгий JSON, санитизация (лимиты: 30 тегов, 12 kw, нижний регистр). Задеплоена 2026-07-18.

**Экономика:** авто-analyze стрелял на КАЖДУЮ голосовую заметку >14 симв. Теперь короткие простые («купить хлеб») размечаются бесплатно; чем больше пользуются — тем реже нужен ИИ. Обратная экономика.

**Проверить вживую:** сказать голосом короткую покупку → тег должен появиться мгновенно без «Анализирую…» (в консоли `[rz:rules] теги локально, без ИИ`). Первая заточка словаря — в консоли `[rz:rules] правила переточены` через ~9с после входа.

### rz-v410 (2026-08-02) — фикс самовольных напоминаний

Женя: «записывал заметки вообще без упоминания напоминаний, а он сам ставил напоминание».
Причина: `parseVoiceReminder` вызывался на КАЖДУЮ голосовую заметку и стрелял на любое
упоминание времени в рассказе. Худший паттерн — «через …» матчил «через дорогу/друга»
(юнит опционален, любое слово) и молча ставил напоминание на +1 час.

Фиксы в `js/app.js` (все ветки покрыты изолированным node-прогоном):
- **Слова-намерения**: `_REMIND_INTENT=/напомн|не забы|уведомлен|будильник|разбуди/i` —
  без них голосовая заметка НЕ становится напоминанием. Для интента агента `SET_REMINDER`
  парсер зовётся с `force=true` (намерение уже подтверждено LLM).
- Тот же гейт в `analyzeText` — «в 15:30» в тексте больше не превращается в напоминание само.
- «через …» ужесточён: слово должно быть числом (цифрой/прописью) либо стоять с единицей времени.
- **Попутный старый баг**: «через 30 минут» ставило напоминание через 30 ЧАСОВ
  (`amount*60` задумывался для «полчаса»=0.5ч, но применялся и к уже-минутам).
- **Попутный старый баг 2**: `\b` не работает с кириллицей в JS → «утром/днём/вечером/ночью»
  никогда не срабатывали. Заменено на `includes` (+вариант «днем» без ё).

## Последние большие изменения (сессия 2026-06-09 → 06-16)

### Тёмная тема (v379–v386)
- Fog через CSS-переменные `--fog` + pre-computed `--fog-72/42/...` (НЕ `color-mix` — не поддерживается на старых iOS Safari).
- Тёмные карточки/кнопки/шапка/лого/дата; кнопки агента (`.new-note-btn` — отдельный класс!) тёмное стекло.

### Офлайн + скорость запуска (v387)
- **supabase-js вендорится локально** `js/vendor/supabase.js` (CDN без `crossorigin` = opaque response = SW не кэшировал = офлайн умирал).
- Мгновенный вход с `rz_last_user` (сессия проверяется в фоне). Лого без FOUT (гейт `fonts-ready`).

### Перегрев + плавность (v388–v390)
- `nnb-float`/`dot-pulse`/`agent-glass` → transform/opacity-only (box-shadow в keyframes грел GPU).
- `backdrop-filter` снят с движущихся кнопок. Под открытым оверлеем фоновые анимации на паузе.
- Анимации появления/переходов — мягкое перо `cubic-bezier(.22,1,.36,1)`, без overshoot.

### «Все заметки» (v392–v393)
- Время-группы Сегодня/Вчера/Неделя/Ранее, спокойные карточки без шума, выплывающая лента (гейт `.reveal` — без моргания на «показать ещё»).

### Десктоп (v394–v395)
- Шапка = PWA-стекло (blur+saturate). Меню (`.jarvis-quick`) и кнопки агента (`.home-act-row`) переезжают в шапку на ≥1000px (`_syncDesktopHeader` + matchMedia). Лента на всю ширину, правый рейл убран. **Не до конца вылизано — нужен живой тест на десктопе.**

### Логика агента (v396–v398)
- Живая карточка «Разбираюсь…» сразу при запросе → плавно превращается в ответ. Разборы/анализы не автозакрываются.
- Агент слышит через родной `SpeechRecognition` (как голосовая заметка), Yandex/Groq — резерв.
- Fix: клиент шлёт реальную `sample_rate` (был дефолт 16000 при аудио 48000 → Yandex слышал кашу).
