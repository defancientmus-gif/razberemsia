# Project Memory — Разберёмся

Каноническая папка памяти, промтов и рабочих документов проекта.

## Читать первым

1. `current/2026-05-19_PROJECT_BRIEF.md` — что такое проект и что сейчас работает.
2. `current/2026-05-19_AGENT_RULES.md` — правила работы для AI/разработки.
3. `current/2026-05-19_TODO.md` — актуальные задачи.
4. `current/2026-05-19_AI_MEMORY.md` — память, Supabase и будущая архитектура.
5. `current/2026-05-19_RELEASE_CHECKLIST.md` — что проверять перед пушем/показом.
6. `current/2026-05-19_CHANGELOG.md` — история изменений.

## Принцип

`current/` — только живой, короткий контекст.  
`archive/YYYY-MM-DD/` — старые промты, большие чеклисты и исходные документы, сохранённые для восстановления истории.

Не копировать старые тексты обратно целиком. Если из архива нужен смысл, переносить его в `current/` коротко: решение, причина, файл, следующий шаг.

## Архив по датам

- `archive/2026-05-15/` — ранняя философия и короткий мастер-промт.
- `archive/2026-05-17/` — аудит проекта.
- `archive/2026-05-18/` — AI Memory, Claude/Codex master-файлы, релизные чеклисты, стратегия продвижения.
- `archive/2026-05-19/` — состояние корневых `MASTER/CLAUDE/PROJECT_CONTEXT/TODO` перед чисткой.

## Что не трогать без явной просьбы

- runtime приложения: `index.html`, `js/app.js`, `sw.js`;
- PWA-иконки и картинки;
- Supabase RLS и auth;
- рабочий сценарий заметок и облачной синхронизации.
