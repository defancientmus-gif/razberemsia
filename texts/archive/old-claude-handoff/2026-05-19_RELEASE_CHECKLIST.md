# Разберёмся — Release Checklist

Последнее обновление: 2026-05-19

Использовать перед пушем, после пуша и перед показом человеку.

## Перед пушем

- [ ] `git status --short --branch` понятен.
- [ ] В staged нет мусора: contact-файлов, случайных `incoming/`, `.DS_Store`.
- [ ] Если менялся frontend: `node --check js/app.js`.
- [ ] Если менялся `index.html`: проверить inline scripts.
- [ ] Если менялся frontend/PWA cache: поднять `CACHE` в `sw.js`.
- [ ] Если менялась Supabase-схема: есть SQL и fallback/order plan.

## Базовый сценарий

- [ ] Открывается экран входа или приложение без белого экрана.
- [ ] Вход по email OTP работает.
- [ ] Облачные заметки загружаются.
- [ ] Новая заметка сохраняется.
- [ ] После обновления страницы заметка остаётся.
- [ ] На телефоне/PWA подтягиваются те же заметки.

## AI

- [ ] `✦ AI` не меняет исходный текст без подтверждения.
- [ ] Ошибки AI показаны коротко и понятно.
- [ ] Нет прямых AI API keys в клиенте.
- [ ] Edge Function получает JWT пользователя.

## UX

- [ ] Новая заметка заметно появляется в ленте.
- [ ] Нет наложений текста на мобильном экране.
- [ ] Основной сценарий понятен без объяснений.
- [ ] Тон не превращается в школу/экзамен/таск-менеджер.

## После пуша

- [ ] Проверить публичный URL.
- [ ] Проверить PWA/телефон, если менялся cache.
- [ ] Записать в changelog только значимые изменения.
