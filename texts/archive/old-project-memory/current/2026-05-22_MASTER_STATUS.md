# Разберёмся — Мастер-статус
Обновлено: 2026-05-22 · SW: rz-v127 · Версия: v5.30+

---

## Суть продукта (неизменно)

**Голосовой AI-агент с памятью для людей, которым сложно пользоваться технологиями.**

```
Говоришь голосом → агент понял → сделал → показал карточку «Вижу»
```

Блокнот — это память агента, не суть продукта.
Аудитория: пожилые, люди с низкой цифровой уверенностью, цифровой стресс.
Закон: «Если человек чего-то не понимает — это нормально. Разберёмся.»

---

## Что работает прямо сейчас ✅

### Ядро
- Вход по email OTP (Supabase) — работает, Confirm email отключён
- Заметки: создание, редактирование, удаление, корзина
- Синхронизация в Supabase (`user_state` → JSON-блоб)
- PWA: офлайн fallback, SW-кеш, иконки
- Голосовой ввод (Web Speech API)

### AI
- AI-анализ заметки: summary, tags, actions (Edge Function `ai`)
- Многоходовой диалог внутри заметки (mode: note / chat, history 12 сообщений)
- AI-память: `ai_memory` в localStorage + Supabase колонка
- Системный промпт v2: один вопрос, без «к сожалению», примеры диалогов

### Напоминания
- Клиентский планировщик через SW `setTimeout` (работает пока браузер открыт)
- **VAPID Web Push через Supabase Edge Function** ✅ — сделано (серверные push когда приложение закрыто)
- Голосовой парсер времени: «завтра в три», «через час», «в пятницу вечером»
- In-app баннер (без дублирования с SW)

### UI (последние сессии)
- Drill-down навигация по заметкам (3 уровня: разделы → список → заметка)
- Главный экран: карточки-уведомления + светофор (🔴🟡🟢) + свайп-удаление
- Панель напоминаний: по центру, pop-анимация, умное время
- Нижняя панель: Новая заметка | Голос | Блокнот AI | Напомнить
