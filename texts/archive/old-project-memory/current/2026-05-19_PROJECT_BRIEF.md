# Разберёмся — Project Brief

Последнее обновление: 2026-05-19

## Суть (обновлено 2026-05-21)

`Разберёмся` — голосовой AI-агент с памятью для людей, которым сложно пользоваться технологиями.

Одна строка:

> Говоришь голосом — агент понимает, делает и показывает что сделал. Без меню, без кнопок, без стресса.

Главный закон:

> Если человек чего-то не понимает — это нормально. Разберёмся.

Это не блокнот с AI. Блокнот — это память агента.
Агент — это Джарвис на минималках: снимает рутину будней, помогает людям с ограниченными возможностями.

**Что агент умеет (v1 план):**
- Создать заметку голосом
- Поставить напоминание / будильник голосом
- Ответить на бытовой вопрос
- Найти врача / помочь сформулировать жалобы (медицинский навигатор, не советник)
- Помнить пользователя между сессиями (сжатый профиль)

**Чего агент не делает:**
- Не даёт медицинских советов (только навигация к врачу)
- Не объясняет код и технологии
- Не выходит за пределы своего домена

## Аудитория

- люди с низкой цифровой уверенностью;
- пожилые люди;
- люди, которые боятся “нажать не туда”;
- пользователи, которым сложны пароли, коды, аккаунты, приложения, интернет и AI;
- люди в цифровом стрессе.

## Тон продукта

- спокойно;
- коротко;
- без стыда;
- без экзамена;
- без технического жаргона;
- с уважением к сумбурным, коротким и “неидеальным” заметкам.

## Текущее состояние

- Публичный сайт: `https://defancientmus-gif.github.io/razberemsia/`.
- Версия интерфейса: `v4.13`.
- Runtime: `index.html` + `js/app.js`.
- PWA: `manifest.json`, `sw.js`, cache `rz-v66`.
- Вход: Supabase email OTP, почта -> 6-значный код -> сессия.
- Данные: Supabase `public.user_state` + scoped `localStorage`.
- Таблица `user_state`: `user_id`, `notes`, `trash`, `history`, `ai_memory`, `name`, `updated_at`.
- AI endpoint клиента: `/functions/v1/smooth-processor`.
- Edge Function источник: `supabase/functions/smooth-processor/index.ts`.
- `supabase/functions/ai/index.ts` пока считать legacy-дубликатом до отдельной чистки.

## Что уже работает

- вход по email-коду;
- загрузка и сохранение заметок в Supabase;
- PWA и офлайн fallback;
- домашняя чат-лента заметок;
- редактор заметки;
- категории, списки, корзина, история;
- голосовой ввод через Web Speech API;
- AI-анализ заметки: `summary`, `tags`, `actions`;
- сохранение `aiTags` и `aiSummary` в заметке;
- облачная колонка `ai_memory`;
- fallback, если `ai_memory` временно отсутствует в схеме.

## Продуктовые правила

- Заметки и облако — ядро продукта. Не ломать ради AI-слоя.
- AI не меняет исходный текст без подтверждения.
- Не превращать каждую мысль в задачу.
- Показывать одну полезную подсказку за раз.
- Чат-лента должна быть самопонятной: видно, что человек пишет в живую хронологию заметок.
- Новая заметка должна появляться заметно, с понятной датой/днём.
- Прошлые дни в ленте должны уметь сворачиваться.

## Критерий качества

Перед новой функцией спросить:

- человеку станет спокойнее?
- он поймёт это без объяснений?
- заметки стали надёжнее?
- это не создаёт стыда?
- это работает на телефоне?
