# Сессия 20 мая 2026 — Итоги вечера

Работали вместе над приложением «Разберёмся». Ниже полный список исправлений, фич и идей.

## ✅ Исправления (баги)

### SW / кеш
- Поднят кеш SW: `rz-v68` → `rz-v69` → `rz-v70` → `rz-v71` → `rz-v72` → `rz-v73` → `rz-v74` → ... → `rz-v89`
- Каждый раз принудительно сбрасывал у браузеров старый `js/app.js` и `index.html`

### AI-панель
- **AI-панель показывала снимок прошлой заметки** — при открытии нового листа `_aiOn`, `ai-panel`, `ai-panel-body`, `dataset.aiTags/aiSummary` не сбрасывались. Добавлен полный сброс в `_openSheet()`
- **AI-строка застревала по центру экрана** — следствие того же бага, теперь устранено
- **«Можно сделать» — баг сворачивания** — заменили простой `scrollHeight` на анимацию через `maxHeight:'none'` → measure → `requestAnimationFrame` для надёжного expand/collapse
- **Кнопка «Улучшить текст» внутри AI-панели** — удалена (была задвоена, мешала)

### Исправление текста (кнопка-карандаш ✏️)
- **`SUPABASE_EDGE_URL` указывал на `smooth-processor`** вместо `ai` — все запросы `rewrite` падали с 404/unknown action
- **Функция `toggleSpellFix()` не существовала** — кнопка в шапке вызывала несуществующую функцию
- Реализована правильная логика: 1-е нажатие → AI улучшает текст, кнопка подсвечивается; 2-е нажатие → откат к оригиналу
- Сброс `_spellOriginal` при открытии нового листа

### Авто-сохранение идей
- **`\b` не работает с кириллицей в JS** — `^идея\b` никогда не срабатывало (символ "я" не является `\w` в JavaScript)
- Исправлено: заменили на `^идея([^а-яёА-ЯЁa-zA-Z]|$)` — теперь «Идея.», «Идея:», «Идея — текст» корректно определяются

### Списки
- **Список нельзя было открыть для редактирования** — клик по пузырю ничего не делал
- Исправлено: добавлен `cursor:pointer` + `bbl.addEventListener('click', () => openListSheet(n.id))`
- **`_openNoteWith()` не учитывал тип `list`** — теперь направляет в `openListSheet()`

### Экран запуска
- **Текст «Разберёмся» дёргался при открытии PWA** — два отдельных экрана (`#splash` и `#auth-screen`) показывали его с разных позиций и разными анимациями
- Удалён `#splash` полностью
- `#auth-screen` теперь виден сразу при загрузке — он сам и есть заставка
- Пока идёт проверка сессии — три пульсирующие точки
- Нашли сессию → экран плавно гаснет; не нашли → карточка с полем почты мягко выезжает
- Логотип и текст стоят на месте с первого кадра

### Панель «Помочь проекту»
- Панель была прозрачной — использовала `class="sheet-panel"` (CSS не определён как класс)
- Заменена на собственные классы: `fb-hdr`, `fb-ta`, `fb-footer`, `fb-body`
- Кнопка не срабатывала с первого нажатия — убран `requestAnimationFrame` в `openFeedbackSheet()`
- Добавлен `.fb-drag`, `.fb-to-row`, `.fb-avatar`, `.fb-to-badge` — понятно, что сообщение разработчику

### Уведомления
- Дублировались: SW и страница оба стреляли уведомлением
- SW — единственный источник `showNotification()`. Страница только in-app баннер
- `tag: n.id` в SW предотвращает дубли с одним id

### Раздел «Заметки» — фильтр по дате
- Фильтр по дате матчил только `n.reminder` — при выборе даты без напоминания заметки исчезали
- Исправлено: матчит `createdAt || updatedAt || reminder`
- Счётчики папок теперь получают отфильтрованный список, а не весь `all`

### CSS / производительность
- Заменены все `transition: all` на конкретные свойства
- Убрана анимация `@keyframes border-pulse`
- Убран `will-change: transform` с `.bubble`
- Удалено 11 лишних `-webkit-tap-highlight-color`
- Удалены мёртвые CSS-правила: `.sheet-kb-hint`, `.note-audio-badge`

## ✨ Новые функции

### iOS-напоминания через Apple Calendar
- Экспорт `.ics` (RFC 5545) с `VALARM TRIGGER:PT0S` — одно нажатие в системном диалоге
- Кнопка 📅 рядом с полем напоминания в редакторе
- Кнопка «Установить напоминание» в панели колокольчика
- `openInputSheetWithReminder()` — открывает редактор и фокусирует поле напоминания

### Голосовые напоминания
- `parseVoiceReminder(text)` — умный парсер русских временных фраз
- Понимает: «через N часов/минут», дни недели, «сегодня/завтра/послезавтра», «утром/днём/вечером/ночью», «в 15:00», числа словами («в три», «в половину четвёртого»)
- Возвращает ISO datetime или null

### Микроблог / AI-чат внутри заметки
- `n.aiChat: [{role, text, ts}]` — история переписки внутри каждой заметки
- Нажатие на пузырь ответа AI → открывается заметка с историей чата
- Внутри заметки: `#note-chat` + `#note-chat-input-row` для продолжения диалога
- Контекст последних 6 сообщений передаётся в `chat_reply`
- На главном экране — только последнее сообщение AI, без лога переписки
- Сердечко (заливка/контур) вместо стрелок лайк/дизлайк

### AI-пузыри
- Стиль: glass без тяжёлого `backdrop-filter`, совпадает с дизайном заметок
- Меньший левый отступ на мобильном

### Холодный старт PWA
- Тихий retry через 3 секунды вместо мгновенного тоста «работаем локально»
- iOS нужно ~3с для network после запуска PWA

### Авто-сохранение идей в репозиторий
- Edge Function action `save_idea` — GitHub Contents API, папка `ideas/`
- Двойной триггер: тег «идеи» от AI + regex `^идея` в начале текста
- Тост «✦ Идея сохранена в репозиторий»

### Версия v5.0
- Поднята во всех местах: тайтл, экран входа, шапка приложения
