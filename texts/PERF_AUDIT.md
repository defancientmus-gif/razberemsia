## 🔴 Критично (фиксить первым)

### 1. backdrop-filter — 94 слоя, многие видны одновременно
Значения blur: `blur(50px)` на cal-popup, `blur(40px)` на sheet, `blur(32px)` на tag/qrem/remind листах, `blur(30px)` на cat-dropdown.
На iOS каждый `backdrop-filter` = отдельный GPU-проход. Когда открыт sheet поверх ленты — одновременно видны 3–4 слоя blur 30–50px.
→ **Решение:** снизить все blur до max 12px. `blur(50px)` → `blur(10px)`, `blur(40px)` → `blur(10px)` итд. Разницу на глаз почти не видно, прирост FPS значительный.
→ **Эффект:** ~30–50% прироста отзывчивости при открытии оверлеев.

### 2. saveNotes → _reloadViews подряд — 14 мест
В каждом из 14 мест после `saveNotes()` сразу вызывается `loadHomeFeed()` + `loadNotes()`. Каждый вызов перерисовывает DOM полностью. Цепочки:
- строки 1398–1400: `saveNotes → loadHomeFeed+loadNotes`
- строки 2231–2234: `saveNotes → _reloadViews`
- строки 4025–4026, 4038–4039 — то же

→ **Решение:** уже есть `loadAll()` с дебаунсом 40ms — использовать его ВЕЗДЕ вместо прямых вызовов `loadHomeFeed()/loadNotes()`. Заменить все 14 мест на `loadAll()`.
→ **Эффект:** при быстрых действиях (удалить/восстановить/редактировать) количество DOM-перерисовок снизится в 2–4 раза.

### 3. 36 `infinite` CSS-анимаций
Все `hf-dot-*` пульсации (`dot-pulse-red/amber/green`) запускаются на каждой карточке с напоминанием или AI-тегом. В ленте из 25 заметок это 25 одновременных `@keyframes` с `box-shadow` изменением.
`box-shadow` в анимации → layout invalidation → дорого.
→ **Решение:** убрать `box-shadow` из `@keyframes`, анимировать только `opacity` + `transform:scale()`.
→ **Эффект:** ~20% снижение нагрузки на GPU при скролле ленты.

## 🟡 Важно

### 4. saturate(2.2) на всегда видимых элементах
`backdrop-filter:blur(50px) saturate(2.2)` на `.cal-popup` (строка ~561 index.html).
`saturate` дороже `blur` на мобиле — добавляет дополнительный render pass.
→ Убрать `saturate()` отовсюду. Заменить на `brightness(1.05)` если нужен эффект, или вовсе убрать.

### 5. js/app.js 328 KB — весь код в одном файле
При каждом запуске парсится 7276 строк. На слабых устройствах первый parse занимает 200–400ms.
→ Вынести константы (STRIPES, ICONS, MRU, MGN и т.д.) в начало; это позволит браузеру кэшировать V8 bytecode эффективнее.
→ Удалить пустые функции-заглушки: `_renderTagPickerBody(){}`, `renderSectPills(){return;}` — ~30 строк мёртвого кода.

### 6. `_qremCalH(){}` `_qremCalM(){}` `_qremCalSave(){}` — пустые функции
Строки 2809–2812: три пустые функции оставшиеся от рефакторинга.

### 7. index.html 300 KB — много inline стилей и мёртвого CSS
`cal-add-ov` и `cal-add-sheet` используют 100% inline style атрибуты вместо классов.
Есть закомментированные блоки `.remind-item{}`, `.remind-item-top{}` и т.д. (~50 строк).
