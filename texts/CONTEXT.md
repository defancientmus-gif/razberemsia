# Контекст продукта

`Разберёмся` - голосовой AI-агент с памятью для людей, которым сложно пользоваться технологиями.

Одна строка:

> Говоришь как умеешь -> агент понял -> сделал -> показал понятный результат.

Главный закон:

> Если человек чего-то не понимает - это нормально. Разберёмся.

## Для кого

- пожилые люди;
- люди с низкой цифровой уверенностью;
- люди в цифровом стрессе;
- те, кому сложны пароли, коды, аккаунты, интернет, настройки.

## Тон

Спокойно, коротко, без стыда, без экзамена, без технического жаргона.

Агент не должен звучать как инструкция. Он должен звучать как умный спокойный помощник рядом.

## Принцип агента

Агент не просто отвечает. Он организует хаос.

Не "у вас конфликт в 15:00", а "я вижу конфликт, давайте перенесем или напомним заранее".

Не "не могу", а "вот что можно сделать сейчас".

Исключение: реальный вред жизни, мошенники, опасные действия.

## Границы продукта

- Голос - главный путь.
- Заметки - память агента, а не просто блокнот.
- AI не меняет исходный текст без подтверждения.
- Не превращать приложение в тяжелый таск-менеджер.
- Медицина - навигация к врачу, не диагнозы.

## Runtime

- Входная точка: `index.html`
- Основной клиент: `js/app.js`
- PWA: `manifest.json`, `sw.js`
- Текущий cache смотреть только в `sw.js`, строка `const CACHE`
- Прод: https://defancientmus-gif.github.io/razberemsia/
- Деплой: `./deploy.sh "описание"` или вручную с обязательным cache bump

## Данные

- Auth: Supabase email OTP.
- Основное хранение: `public.user_state` JSON + таблица `notes`.
- Push: `push_subscriptions`, `reminders`.
- Папки: `user_folders`, `tag_folders`.

## AI

- Клиентский endpoint: `/functions/v1/ai`.
- Код: `supabase/functions/ai/index.ts`.
- Legacy: `smooth-processor`, не источник правды.
- Модель по env: `ANTHROPIC_MODEL`.
- Секреты: `ANTHROPIC_API_KEY`, `GROQ_API_KEY`, `GITHUB_TOKEN`.

## Идеи

- Активные ближайшие: `texts/IDEAS_NEAR_TERM.md`.
- Будущие направления: `texts/IDEAS_FUTURE.md`.
- Beta-магия: `texts/IDEAS_BETA_DELIGHTERS.md`.
- Сделанное/спящее: `texts/IDEAS_DONE_OR_DORMANT.md`.
- `ideas/` - legacy raw-история автосохранений. Не считать главным планом.

`save_idea` должен писать в `texts/IDEAS_NEAR_TERM.md`. В `rz-v277` клиентский вызов исправлен: идеи отправляются и из AI-анализа, и из обычного `Сохранить`; Edge Function `ai` задеплоена, нужен живой тест GitHub-записи.
