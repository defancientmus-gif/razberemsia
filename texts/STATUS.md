# Статус

Обновлено: 2026-05-31. Runtime cache: смотреть `sw.js`, сейчас `rz-v282`.

## Работает

- Вход по email OTP.
- Заметки, списки, редактор, корзина, история.
- Supabase sync: `user_state` + таблица `notes`.
- Пользовательские Разделы и AI-папки.
- PWA/offline fallback.
- Быстрый PWA update через `skipWaiting()`, `clients.claim()` и один reload на `controllerchange`.
- Голосовой ввод: Web Speech API + fallback через Edge Function.
- AI-анализ заметки: summary, tags, actions.
- AI-чат внутри заметки.
- Кнопка исправления текста.
- Напоминания, push, парсер голосового времени.
- Голосовой агент с действиями создания заметок, напоминаний, поиска и плана.

## Открытые проблемы

1. `save_idea` требует периодического живого теста.
   - Локальный код отправляет `save_idea` в Edge Function из AI-анализа и из обычного `Сохранить`.
   - Edge Function локально пишет в `texts/IDEAS_NEAR_TERM.md`.
   - Edge Function `ai` задеплоена 2026-05-29 после правки.
   - Тег идеи канонический: `идея`; `идеи`, `idea`, `ideas`, `idei`, `ideya`, `ideja` не являются отдельными папками.
   - Экранная системная папка для этого тега называется `Входящие`.

2. Контекстный репозиторий был рассинхронизирован.
   - Активные `texts/*.md` были локально untracked.
   - GitHub видел только часть новой структуры.
   - Старый `project-memory` оставался в индексе как удаленный.

3. Handoff-скрипт был устаревшим.
   - Ссылался на `project-memory/current/...`.
   - Копировал `smooth-processor`.
   - Должен быть переведен на `texts/` и `supabase/functions/ai/index.ts`.

4. Возможны обходные функции и старые дубли.
   - Перед удалением/переносом всегда искать по коду.
   - Не считать отсутствие видимой кнопки доказательством, что функция мертвая.
