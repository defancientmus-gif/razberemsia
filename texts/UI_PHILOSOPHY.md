# UI Philosophy — «Разберёмся»

> Этот файл читать ПЕРЕД любой правкой визуала.
> Нарушение правил здесь = Женя злится, откат.

---

## Дух интерфейса

**Не Google. Не Material Design. Не Bootstrap.**

Ориентир — нативный iOS, приложения уровня Things 3, Fantastical, Bear.
Стекло, воздух, типографика. Ничего лишнего.

Интерфейс не должен «стараться выглядеть красиво» — он просто должен работать красиво.
Декорации которые надо объяснять — не работают. Убрать.

---

## Что НИКОГДА не делать

### Декоративный мусор
- ❌ Цветные черточки/полоски внизу или сбоку карточек
- ❌ Подчёркивания у текста (кроме ссылок)
- ❌ Разноцветные бейджи «для красоты»
- ❌ Градиентные рамки вокруг карточек
- ❌ Тени которые заметны глазу (box-shadow > 12px spread — стоп)
- ❌ Анимации на каждом элементе — только там где они несут смысл
- ❌ Emoji в UI-компонентах (кнопки, лейблы) — только SVG иконки

### Google-style паттерны (запрещены)
- ❌ Ripple-эффект при нажатии
- ❌ Floating Action Button с тенью 45° ниже
- ❌ Material elevation (1dp, 2dp, 4dp shadows)
- ❌ Filled + outlined варианты кнопок в одном экране
- ❌ Bottom navigation с цветными иконками

### Типичные ошибки Claude
- ❌ Добавить `::before` или `::after` «для акцента» — нет
- ❌ `border-bottom: 2px solid [акцентный цвет]` на карточке — нет
- ❌ `background: linear-gradient(...)` на карточке когда достаточно одного цвета
- ❌ Добавить иконку туда где её не было — только если задача это требует
- ❌ Изменить цвет кнопки «чтобы выделялась» — без задачи на UX

## Что ВСЕГДА делать

### Карточки
- Матовое стекло: `background: oklch(1 0 0 / .38); backdrop-filter: blur(12px)`
- Тонкая рамка: `border: 1px solid oklch(0.88 0.02 210 / .40)`
- Радиус: 16–20px для средних, 12px для мелких, 28px для шитов
- Тень максимум: `box-shadow: 0 2px 12px oklch(0 0 0 / .06)` — едва заметная
- Отступы внутри: 12–16px, дышать должно

### Цвет
- Система: `oklch()` везде, без hex/rgb
- Фон: `oklch(0.96–0.98 0.005–0.015 210)` — почти белый с холодным оттенком
- Основной текст: `oklch(0.20 0.02 210)` (~#1a1f2a)
- Вторичный текст: `oklch(0.55 0.02 210)` (~#7a8a9a)
- Акцент (кнопки «сохранить»): `oklch(0.40 0.14 270)` — фиолетово-синий
- Акцент (ссылки/иконки): `oklch(0.45 0.12 210)` — бирюзово-синий
- Деструктив: `oklch(0.45 0.16 15)` — красный
- Никаких ярких оранжевых, жёлтых, зелёных в фоне карточек

### Типографика
- Заголовки: 600–700 weight
- Тело: 400–500 weight
- Подписи/метаданные: 11–12px, uppercase + letter-spacing для лейблов
- Шрифт UI: `var(--sys)` (системный SF Pro / -apple-system)
- Никаких `font-size: 10px` — минимум 11px

### Кнопки
- Основная: тёмный акцент, белый текст, радиус 14–18px, padding 13–16px
- Вторичная: стекло/прозрачная, рамка, цветной текст
- Деструктивная: `background: oklch(0.90 0.04 15 / .35)`, красный текст
- Активное состояние только через: `:active { opacity: .85; transform: scale(.96); }`
- Никаких кнопок с `border: none; background: none` без хотя бы hover-состояния

### Разделители между элементами списка
- Только если список > 5 элементов И элементы однородные
- Если есть разделитель: `border-bottom: 1px solid oklch(0.88 0.02 210 / .35)`
- Никогда цветной разделитель

### Иконки
- Lucide-style SVG, stroke-width: 1.8–2.2
- Размер: 14–20px в зависимости от контекста
- Цвет: наследуется от текста (`stroke: currentColor`)
- Никаких emoji вместо иконок в компонентах

## Когда добавляешь новый элемент — проверь

```
□ Он нёс бы смысл если убрать?
□ Это уже есть где-то рядом и дублируется?
□ Это видно на белом фоне и на тёмном?
□ Работает ли это без анимации?
□ Объяснил бы я это пользователю 65+ без инструкции?
```

Если хотя бы один ответ «нет» — не добавлять без явной задачи от Жени.

---

## Принцип минимума изменений

Правишь одну вещь → меняешь только её.
Не «заодно улучшаю» карточки, если задача про кнопки.
Не добавляешь `::before` «для красоты» если задача про текст.

**«Я добавил это для полировки»** — красный флаг. Не делать.

---

## Референсы стиля (в голове держать)

✅ Things 3 — чистота, воздух, цвет только где нужен
✅ Bear Notes — типографика, стекло, ноль украшательств
✅ Fantastical — плотность информации без перегруза
✅ iOS нативные шиты (Share Sheet, Maps cards) — стекло, радиус, тени

❌ Google Calendar — слишком плоский, MD-цвета
❌ Notion — слишком серый, desktop-first
❌ Any Material Design app — ripple, elevation, FAB

---

## Когда сомневаешься

Спросить: «Женя, хочу добавить [X] — вот скриншот. Ок?»
Не деплоить визуальные изменения не показав.

> Живой продукт > идеальный код > красивый код.
> Но сломанный UI = мёртвый продукт.
