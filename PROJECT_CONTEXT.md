# Разберёмся — контекст проекта

Последнее обновление: 2026-05-15

## Миссия

«Разберёмся» — спокойный цифровой помощник для людей, которым тревожно, страшно или непонятно взаимодействовать с технологиями.

Главная мысль:

> Если человек чего-то не понимает — это нормально. Разберёмся.

Проект не должен ощущаться как курс, школа или «обучение для чайников». Он должен ощущаться как терпеливый человек рядом: спокойно, понятно, без давления и без стыда.

## Аудитория

- Люди с низкой цифровой грамотностью.
- Пожилые люди.
- Люди, которые боятся «нажать не туда».
- Пользователи, которые не понимают Telegram, VPN, аккаунты, пароли, СМС-коды, перенос данных.
- Люди в состоянии цифрового стресса.

## Тон

- Спокойный.
- Человечный.
- Без сложных терминов.
- Без высокомерия.
- Как хороший родственник или терпеливый помощник.

## Текущая суть продукта

Сейчас это PWA/HTML-прототип с:

- Supabase email OTP-входом;
- заметками;
- блокнотом;
- тревожными сценариями;
- мягким экраном авторизации;
- PWA-иконкой с пером;
- облачной синхронизацией пользовательского состояния.

Главный продуктовый фокус: не просто заметки, а личное мягкое пространство помощи и заботы.

## Важные решения

- Рабочий файл приложения всегда `index.html`.
- Не возвращать Firebase/SMS.
- Не возвращать локальный/dev-вход в публичный UI/JS.
- Публичный вход — Supabase email OTP: почта → 6-значный код → вход.
- Не использовать magic link как основной текущий сценарий, если пользователь отдельно не попросит вернуться к нему.
- Новые функции нельзя добавлять поверх старого дизайна грубо. Сначала думать о вайбе.
- Заметка должна ощущаться как «облачко», а не как форма базы данных.
- Уведомления должны быть тёплыми, не только про штрафы, дела и упрёки.

## Бренд-идея PWA-иконки

Минималистичная отсылка: шапка Питера Пэна + кораблик/путь + перо + точка.

Смысл:

- кораблик — проводник;
- перо — лёгкость и сказочность;
- точка — человек/старт/маяк;
- путь — «разберёмся шаг за шагом»;
- шапка — добрый проводник, игра вместо страха.

Это должна быть собственная метафора, не копия Pied Piper.

## Основные файлы

- `index.html` — главный прототип и входная точка GitHub Pages/PWA.
- `manifest.json` — PWA manifest.
- `sw.js` — service worker.
- `pwa-feather-180.png`, `pwa-feather-192.png`, `pwa-feather-512.png` — PWA иконки.
- `icon-192.png`, `icon-512.png` — совместимые копии для старых ссылок.
- `deploy.ps1` — git add/commit/push.
- `supabase.sql` — таблица и RLS-правила безопасности Supabase.
- `MASTER.md` — главный документ для Codex.
- `Master PROMT/` — мастер-промты и философия проекта.

## Данные и безопасность

- Заметки, корзина, история и имя пользователя хранятся в локальных ключах, привязанных к Supabase `user.id`.
- При email OTP-входе данные синхронизируются в Supabase `user_state`.
- Supabase должен быть защищён RLS-правилами из `supabase.sql`: читать и писать может только владелец `user_id`.
- Старые локальные заметки автоматически мигрируют в пользовательский локальный ключ при первом входе.
- `SUPABASE_ANON_KEY`/publishable key можно хранить в клиенте.
- `service_role` key нельзя просить у пользователя и нельзя вставлять в клиент.

## Правило имён и путей

- Главный HTML всегда называется `index.html`.
- `manifest.json` открывает `/razberemsia/`, а не конкретный HTML-файл.
- `sw.js` кэширует `index.html`.
- После важных PWA/JS-правок повышать cache name в `sw.js`.
- `deploy.ps1` не содержит абсолютных путей и работает из папки, где лежит сам скрипт.
- Старые HTML-копии хранить только в папке `1`.
- На любом ПК источник правды — GitHub-репозиторий `defancientmus-gif/razberemsia`.

## Как продолжать на другом ПК

Один раз на новом устройстве:

```powershell
git clone https://github.com/defancientmus-gif/razberemsia.git
cd razberemsia
```

Перед началом работы в уже скачанной папке:

```powershell
git pull
```

После работы:

```powershell
.\deploy.ps1 "описание изменения"
```

В новом чате Codex написать:

```text
Прочитай MASTER.md, PROJECT_CONTEXT.md, TODO.md и CHANGELOG.md. Продолжаем проект «Разберёмся».
```
