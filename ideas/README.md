# Идеи

Папка автоматически пополняется приложением «Разберёмся».

Когда AI анализирует заметку и определяет тег **«идеи»** — заметка вместе с AI-разбором сохраняется сюда как отдельный `.md` файл.

## Формат файла

```
ideas/ГГГГ-ММ-ДД_<id>.md
```

Каждый файл содержит:
- оригинальный текст заметки
- AI-суть (одно предложение)
- теги
- предложения что можно сделать

## Настройка

Для работы нужен `GITHUB_TOKEN` в Supabase Secrets:
1. Supabase Dashboard → Settings → Edge Functions → Secrets
2. Добавить: `GITHUB_TOKEN` = Personal Access Token с правом `contents:write` на этот репозиторий
3. Опционально: `GITHUB_REPO` = `defancientmus-gif/razberemsia` (уже задан по умолчанию)
