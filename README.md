## Контекст для Claude/Codex

Активная память проекта лежит в `texts/`.

Читать в таком порядке:

1. `CLAUDE.md`
2. `texts/README.md`
3. `texts/ROUTER.md`
4. `texts/SNAPSHOT.md`
5. `texts/NEXT.md`
6. дальше только файлы из маршрута задачи.

`texts/archive/` и `ideas/` - архив/legacy, не ежедневный контекст.
