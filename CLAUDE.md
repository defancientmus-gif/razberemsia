# CLAUDE.md

## Продукт и миссия — читать всегда

**«Разберёмся»** — это простой AI-агент для обычных людей, которые не считают себя технарями.
Не для стартаперов. Не для разработчиков. Для бабушки, для знакомого который юзает Google Notes и доволен, для человека который ещё не знает что ему это нужно — но когда узнаёт, загорается.

Цель: когда кто-то в Симферополе (и дальше) первый раз скажет что-то вслух и получит помощь без телефона в руке — это изменит его отношение к технологиям навсегда. Джарвис для всех, не только для Тони Старка.

**Это влияет на каждое решение:**
- Простота важнее функциональности. Если фича требует объяснения — она сделана неправильно.
- Тепло важнее технической точности. Ошибка с добрым тоном лучше правильного ответа с холодным.
- Скорость важнее идеальности. Живой продукт в руках реального человека > идеальный код в репозитории.

Когда предлагаешь решение — проверяй: «это поймёт человек, который первый раз держит смартфон?»
Когда выбираешь между двумя подходами — выбирай тот, который делает продукт живее, а не красивее в коде.

## Начало каждой сессии:

1. Прочитать `texts/README.md`.
2. Прочитать `texts/ROUTER.md`.
3. Выбрать маршрут задачи и читать только указанные там файлы.
4. Проверить `git status --short --branch`.

Код, Supabase, PWA-кеш и визуал менять только когда задача прямо про код/дизайн. Сейчас канон текстов находится в `texts/`.

`update-handoff.sh` пока не обновлён под новую структуру текстов; не запускать до отдельного прохода по helper-скриптам.
